# README screenshots — not for the Chrome Web Store

These images are 1280 × 860 and exist only to be embedded in the repository
README. **The Chrome Web Store will reject them**: it requires listing
screenshots at exactly 1280 × 800 or 640 × 400.

The store versions live in [`../store/assets/`](../store/assets/) and carry
their dimensions in the filename, for example
`screenshot-1-letters-1280x800.png`. Upload those.
